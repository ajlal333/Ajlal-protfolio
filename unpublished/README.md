# Unpublished assets

Files here are kept in the repository but are **not** copied to the deployed site.

Vite only publishes the contents of `public/`, so nothing in this folder is
reachable at a logicfolds URL.

`Ajlal_Resume.pdf` and `Muhammad_Ajlal_Haider_Resume.pdf` live here because they
contain a personal phone number and were previously served at predictable public
URLs (`/Ajlal_Resume.pdf`, `/Muhammad_Ajlal_Haider_Resume.pdf`) even though no
page linked to them.

The business-facing document is `public/LogicFolds_Credentials.pdf`, generated by
`scripts/build-credentials.py`. It carries no personal contact details.
